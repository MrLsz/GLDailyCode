## 题目描述

假设你正在爬楼梯，需要 `n` 阶才能到达楼顶。每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶？

### 示例

```
输入：n = 2
输出：2
解释：1+1 或 2，共两种

输入：n = 3
输出：3
解释：1+1+1、1+2、2+1，共三种
```

### 约束

- `1 <= n <= 45`

---

## 解题思路

### 核心思想：斐波那契数列 DP

到达第 `i` 阶，最后一步只能从 `i-1` 阶走 1 步、或从 `i-2` 阶走 2 步，因此：

```
dp[i] = dp[i-1] + dp[i-2]
```

这是经典的斐波那契数列，递推关系清晰：

```
n=0: 1（原地不动算一种）
n=1: 1
n=2: 2
n=3: 3
n=4: 5
...
```

### 复杂度分析

| 维度 | 复杂度 |
|------|--------|
| 时间 | O(n) — 一次遍历 |
| 空间 | O(n) — dp 数组（可滚动优化到 O(1)） |

---

## 代码实现

### Java

```java
public class Leetcode_70 {
    public int climbStairs(int n) {
        if (n <= 2) {
            return n;
        }

        int[] dp = new int[n + 1];
        dp[0] = 1;
        dp[1] = 1;
        for (int index = 2; index <= n; index++) {
            dp[index] = dp[index - 1] + dp[index - 2];
        }

        return dp[n];
    }
}
```

**写法要点**：
- **初始化 `dp[0]=1, dp[1]=1`**：`dp[0]=1` 作为递推基座（走到第 0 阶算 1 种），保证 `dp[2] = dp[1] + dp[0] = 2`
- **边界 `n <= 2` 直接返回 n**：`n=1` 返回 1，`n=2` 返回 2，与 dp 结果一致
- **递推 `dp[i] = dp[i-1] + dp[i-2]`**：本质是斐波那契数列

---

## 关键点总结

1. **斐波那契递推**：`dp[i] = dp[i-1] + dp[i-2]`，爬楼梯是 DP 的入门经典
2. **最后一步分解**：到第 i 阶 = 从 i-1 走一步 + 从 i-2 走两步
3. **空间可优化**：只依赖前两项，可用两个变量滚动替代数组，O(1) 空间
